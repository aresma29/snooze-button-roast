> Dear alarm clock: ringing at 6 a.m. on a Saturday is not a wake-up call, it is a confession that you hate me.

Running `python3 main.py` prints the entry line exactly as written, with nothing added and nothing left out. It finds the entry file next to the script itself, so it works from any working directory.
